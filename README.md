# Git opakování web - AI Hub

Jednoduchý webový projekt vytvořený jako opakování práce s Gitem a GitHubem.

## Autor
Matyáš Průša

## Popis projektu
Webová stránka zaměřená na umělou inteligenci - moji oblíbenou technologii. Stránka obsahuje informace o tom, jak AI revolucionuje práci v IT oboru, praktické aplikace AI a interaktivní prvky demonstrující JavaScript.

## Spuštění projektu
1. Klonuj repozitář:
```bash
git clone git@github.com:MatyMaty15/opakovani_git.git
```

2. Jdi do složky projektu:
```bash
cd opakovani_git
```

3. Otevři soubor `index.html` v prohlížeči:
```bash
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

## Struktura projektu
```
opakovani_git/
├── index.html      # Hlavní HTML soubor
├── style.css       # CSS styly
├── script.js       # JavaScript interaktivita
└── README.md       # Dokumentace
```

## Jak se projekt vyvíjel
Projekt byl vyvíjen pomocí tří hlavních větví:
1. **feature/content** - Přidání obsahu a struktury HTML
2. **feature/styles** - Styling a CSS úpravy
3. **feature/javascript** - Interaktivní prvky a JavaScript

## Git příkazy použité
```bash
git clone git@github.com:USERNAME/opakovani_git.git  # Klonování
git status                                            # Status
git add .                                            # Přidání souborů
git commit -m "feat: ..."                           # Commit
git push                                            # Push na GitHub
git pull                                            # Pull změní
git switch -c feature/nazev                         # Nová větev
git switch main                                     # Přepnutí větve
```

## SSH ověření
SSH připojení bylo ověřeno pomocí:
```bash
ssh -T git@github.com
# Output: Hi MatyMaty15! You've successfully authenticated, but GitHub does not provide shell access.
```
